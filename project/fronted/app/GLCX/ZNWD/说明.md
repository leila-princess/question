### Sider（侧边栏）
- **宽度**: 280px，可折叠至 40px
- **功能**:
  - "新对话"按钮：保存当前对话 → 清空消息 → 生成新sessionId → 刷新历史列表
  - 历史列表：分页显示，点击加载详情，支持单条删除
  - 清空全部：删除所有历史记录

### Content（主内容区）
- **空状态**: 展示机器人图标 + 推荐问题按钮（4个预设问题）
- **对话状态**: 
  - 用户消息：Bubble 组件，右对齐，绿色头像
  - AI 消息：Bubble 组件，左对齐，蓝色头像，包含思考过程和答案两部分
  - 加载状态：显示 Loading 动画

## 四、核心组件说明

### 1. `ThinkingProcessPanel`
思考过程展示面板

- **结构**: 顶部标题栏（可折叠）+ 可滚动内容区
- **交互**: 点击标题栏展开/收起思考过程
- **渲染**: 使用 `react-markdown` 渲染思考内容
- **状态**: 显示"思考中..."或"已完成"
- **自动滚动**: 新内容到达时自动滚动到底部

### 2. `ThinkingPanel`
检索步骤详情面板（历史版本使用）

- **功能**: 展开显示图数据库检索、知识库检索、结果融合的步骤信息
- **子组件**:
  - `Neo4jResultModal`: 图数据库检索结果弹窗
  - `ChromaResultModal`: 知识库检索结果弹窗
- **交互**: 点击信息来源标签可打开详情弹窗

### 3. `Neo4jResultModal`
图数据库检索结果弹窗

- 显示节点列表，包含标签和属性
- 支持高亮当前选中的来源节点

### 4. `ChromaResultModal`
知识库检索结果弹窗

- 按文档分组显示检索结果
- 使用 Markdown 渲染标准文档内容

## 五、SSE 流式接收机制

### `useSSE` Hook (`fronted/app/hooks/useSSE.ts`)
自定义 React Hook，封装 SSE 流式通信

**实现原理**:
1. 使用 `fetch()` + `ReadableStream` 接收流式响应
2. `TextDecoder` 将二进制数据转为文本
3. 按 `\n\n` 分割 SSE 事件块
4. 解析 `event:` 和 `data:` 行
5. 回调函数逐事件通知调用方

**核心 API**:
- `sendMessage(options, onEvent)`: 发送请求，通过回调接收事件
- `stopGeneration()`: 中断请求（AbortController）
- `isGenerating`: 是否正在生成

**SSE 事件处理流程**:
```
thinking_start  →  初始化思考面板
thinking        →  追加思考内容（流式）
tool_call       →  显示工具调用信息（追加到思考过程）
tool_result     →  显示工具返回结果（追加到思考过程）
answer          →  追加回答内容（流式）
done            →  标记思考完成
error           →  显示错误信息
token_limit     →  提示用户开启新对话
```

### API 代理 (`fronted/app/api/znwd/chat/stream_v4/route.ts`)
Next.js API Route，将前端请求代理到后端 Flask 服务

**作用**: 解决跨域问题，直接透传 SSE 流到浏览器

**实现**: 使用 `fetch()` 请求后端，将 `response.body` (ReadableStream) 直接传给 `NextResponse` 保持流式特性

## 六、数据结构

### ChatMessage
```typescript
interface ChatMessage {
  id: string;                       // 唯一标识
  role: 'user' | 'ai';             // 消息角色
  content: string;                  // 原始内容
  thinkingSteps?: ThinkingStep[];   // 检索步骤（历史版本）
  thinkingProcess?: {               // 思考过程
    content: string;                // 思考内容（累积拼接）
    isComplete: boolean;            // 是否完成
  };
  answerContent?: string;           // 回答内容（累积拼接）
}
```

### ThinkingStep
```typescript
interface ThinkingStep {
  type: string;                    // 步骤类型
  message: string;                 // 步骤消息
  status?: 'loading' | 'done';    // 状态
  hits?: number;                   // 命中数
  sample?: string[];              // 示例
  results?: any[];                // 检索结果
  matchedChunks?: any[];          // 匹配片段
  fullStandards?: any[];          // 完整标准
}
```

### HistoryItem
```typescript
interface HistoryItem {
  id: number;
  sessionId: string;
  title: string;
  messageCount: number;
  createdAt: string;
  updatedAt: string;
  messages?: any[];
}
```

## 七、状态管理

使用 React `useState` 进行本地状态管理：

- `messages`: ChatMessage[] — 对话消息列表
- `history`: HistoryItem[] — 历史对话列表
- `sessionId`: string — 当前会话 ID（localStorage 持久化）
- `siderCollapsed`: boolean — 侧边栏折叠状态
- `inputValue`: string — 输入框内容
- `isGenerating`: boolean — 是否正在生成（来自 useSSE hook）

## 八、渲染优化

- `useCallback`: 避免不必要的组件重渲染
- `key` 属性: 列表使用稳定 key 避免 DOM 重建
- `scrollToBottom`: 使用 `useEffect` + `useCallback` 优化滚动
- 懒加载: 历史列表按需加载，支持分页

## 九、API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/znwd/chat/stream_v4` | POST | SSE 流式对话（主接口） |
| `/api/znwd/history` | GET | 获取历史对话列表 |
| `/api/znwd/history` | DELETE | 清空所有历史 |
| `/api/znwd/history/:id` | GET | 获取单条历史详情 |
| `/api/znwd/history/:id` | DELETE | 删除单条历史 |
| `/api/znwd/chat/save` | POST | 手动保存当前对话 |
| `/api/znwd/chat/session/:id` | GET | 按 sessionId 获取会话 |

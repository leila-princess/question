### 使用说明

1. 全文仅两章：`## 1. 试验依据`、`## 2. 试验内容及方法`。
2. 项目树：环境 → **父级项目** → **子级项目**；指标树：父级指标 → 子级指标。
3. 方法正文内条目标号须挂接父小节编号（如父为 `2.1.1.1`，正文内可用 `2.1.1.1.1`…）。
4. 未选考核指标时：**不得**出现 `### 2.2` 及任何 `2.2.x`。
5. 各方法（一）（二）（三）与图库 **SYTJ / SYGC / JGPD** 一致；有 SYNR 则优先连续正文。

图数据库快捷指令集

展示所有节点和关系

```cypher
MATCH (n)-[r]->(m) RETURN n, r, m
```

为已存在的关系添加属性(项目与方法之间)

```cypher
MATCH (a:TestProject {name: "项目B1"})-[r:CON]->(b:TestMethod {Name: "项目B1试验方法"})
SET r.rate = "0.9"
RETURN r
```

（指标与方法）之间关系的属性

```cypher
MATCH (a:Indicator {Name: "最大飞行速度"})-[r:CON]->(b:TestMethod {Name: "指标试验方法"})
SET r.rate = "0.8"
RETURN r
```

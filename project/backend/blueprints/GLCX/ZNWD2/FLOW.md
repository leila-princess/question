# ZNWD2 验收问句

以下问句用于手工验收。消歧规则对齐 [ZNWD1/routing_disambiguation.py](../ZNWD1/routing_disambiguation.py)。

## 查指标（仅设备，与环境无关）

| 问句 | 预期宏 | 说明 |
|------|--------|------|
| 无人机有哪些考核指标？ | 查指标 | Equipment→Indicator |
| 坦克的性能指标有哪些？ | 查指标 | 即使有「高温」等词，若问的是指标，environment=null |
| 考核指标呢？（上文提到某设备） | 查指标 | 按设备查 |

## 查项目（设备 + 可选环境）

| 问句 | 预期宏 |
|------|--------|
| 无人机有哪些试验项目？ | 查项目 |
| 坦克在复杂电磁环境下有哪些试验项目？ | 查项目_有环境 |
| 高原环境下无人机要做哪些测试？ | 查项目_有环境 |

## 查方法

| 问句 | 预期宏 |
|------|--------|
| 无人机有哪些试验方法？ | 查方法_经项目 |
| 高温下无人机用什么试验方法？ | 查方法_经项目_有环境 |
| 按考核指标查无人机的试验方法 | 查方法_经指标 |
